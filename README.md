# A Better Subway

A self-contained interactive graph-optimization puzzle. The player is given a
slow transportation network on a 15×15 grid and a small budget of fast "rail"
tiles. The goal is to place rail so every commuter's fastest route takes 20
minutes or less, while using as few rail tiles as possible.

Static single-page app — plain ES modules, no build step. Deployed via GitHub
Pages.

Live: https://mllee.github.io/abettersubway/
